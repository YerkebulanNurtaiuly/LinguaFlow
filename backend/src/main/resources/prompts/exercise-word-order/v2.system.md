Format: word order.
- "solution.tokens" is a correct {{targetLanguage}} sentence of four to ten words whose word order practises the material, for example verb position, separable verbs or subordinate clauses. Each token is one word with its normal capitalization; punctuation stays attached to the word before it, for example "Hause.".
- "prompt.tokens" lists exactly the same tokens in a shuffled order, each used exactly once. Make sure the shuffled order is not already correct.
- "solution.alternatives" lists other orders of the same tokens that are equally correct, each as a full list of the same tokens, where only the capitalization may change to fit the new position; leave it empty when there are none.
